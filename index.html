✓ VAPT REPORT TEAM OF 2 · OPERATOR

Innovex VAPT — Web Server Penetration Test

Nmap · OpenVAS · Gobuster · Nikto · Hydra · searchsploit · PwnKit

Black-box VAPT on a provided web server VM across 6 phases, following the OWASP Testing Guide and PTES, ending in a 66-page report with risk ratings and fixes for every finding.

  • 20 vulnerabilities found: 1 critical, 10 high, 7 medium, 2 low
  • SQL injection login bypass rated CVSS 9.8, plus local file inclusion and broken access control
  • Chained an anonymous FTP credential leak → SSH brute-force → CVE-2021-4034 (PwnKit) for a root shell
WHAT I LEARNT

This engagement showed me how small findings compound — an anonymous FTP login looks minor on its own, but paired with password reuse it became a root shell. It changed how I read a scope: not each finding in isolation, but how an attacker would chain them together.

✓ PRESENTATION + LIVE LAB TEAM · RESEARCHER

CVE-2017-0166 — LDAP Elevation of Privilege via NTLM Relay

Kali Linux · Responder · ntlmrelayx.py · Impacket · VMware Workstation

Group presentation and live lab (2-person team) demonstrating a full NTLM-relay-to-LDAP attack chain against Active Directory, from vulnerability research to a working proof of concept.

  • CVSS 8.1 (HIGH) — researched and scored the vulnerability from scratch
  • Covered 4 identification methods: registry check, patch verification, LDAP query test, event log monitoring
  • Live 3-VM lab: Kali attacker → Windows 10 victim → Windows Server 2016 DC, ending in full domain hash extraction
Watch the live demo
WHAT I LEARNT

Scoring the CVE myself before touching the exploit changed how I read a vulnerability — probability and impact first, technique second. Presenting the lab live also meant our setup had to hold up in front of an audience, not just work once while we were building it.

✓ NETWORK DESIGN TEAM OF 3 · PHYSICAL LAYER

ISNF — Secure Network Design for SP's Cyber Wargame Centre

Cisco Packet Tracer · VLANs · HSRP · ACLs · Dual ISP

Enterprise network proposal for 6 cyber labs across 3 floors of Block T20, covering design, high availability, security controls and hardware. My part: the physical topology in Packet Tracer, the report and the slides.

  • Laid out 31 network devices and 5 servers across Levels 2, 3 and 4
  • 8 VLANs (/27 subnets) separating each lab, with HSRP core redundancy and dual-ISP failover
  • Extended ACLs blocking student access to staff and SOC servers, tested with ping
WHAT I LEARNT

Laying out the physical network made me think about the real building, not just the diagram — where the server rooms sit, which labs share a switch, and where access points actually reach. Walking the site and taking photos first made the design much easier to justify.

AWS CLI · IAM · S3 · SSRF

Competed in IYCEP, an online CTF, across Web/Cloud, Reverse Engineering, Cryptography and Binary Exploitation categories. Solved Catviewer: an image-fetch feature using Python's urlopen() also accepted file://, letting me read local files and pivot into leaked Lambda environment credentials.
